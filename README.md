# Inkjet KGK CCS3000 — Scan & Send

แอปเดสก์ท็อป (Python + Tkinter) สำหรับสแกน QR Code / Barcode แล้วส่งข้อมูลเข้า Text module ของเครื่องพิมพ์อิงค์เจ็ท KGK CCS3000 ผ่านเครือข่าย LAN (TCP/IP)

## วิธีแบ่งข้อมูลเข้าแต่ละ Module

ตั้งจำนวนตัวอักษรต่อ field (เช่น 40) และหมายเลข Module (เช่น `497,498,499,500`) ในหน้า **ตั้งค่า** แอปจะตัดข้อมูลที่สแกนได้ตามลำดับ:

| ตัวอักษรที่ | ส่งไปที่ |
|---|---|
| 1 – 40 | Module 1 (497) |
| 41 – 80 | Module 2 (498) |
| 81 – 120 | Module 3 (499) |
| 121 – 160 | Module 4 (500) |

- ข้อมูลสั้นกว่า 160 ตัว → เติม Space ต่อท้ายให้ครบอัตโนมัติ
- ข้อมูลยาวเกิน 160 ตัว → ปฏิเสธและ **ไม่ส่ง** อะไรเข้าเครื่องพิมพ์
- ระหว่างสแกน ตารางในหน้า "สแกน" จะแสดงตัวอย่างการแบ่งข้อมูลทันที (ยังไม่ส่ง)

## หน้าตั้งค่า — ปุ่มทดสอบการเชื่อมต่อ

กด **ทดสอบการเชื่อมต่อ** → แอปเชื่อมต่อเครื่องพิมพ์ด้วยค่าที่กรอกอยู่ในฟอร์ม (ไม่ต้องบันทึกก่อน) และถ้าเชื่อมต่อได้ จะส่งข้อความทดสอบ `TEST M<เลข module>` ไปที่ **ทุก Module** แล้วสรุปผลรายโมดูล

> ข้อความใน Module จะถูกแทนที่ด้วยข้อความทดสอบ ระบบจึงถามยืนยันก่อนส่งทุกครั้ง

## ติดตั้งและรัน

```bash
pip install -r requirements.txt
python ccs3000_app.py
```

ค่าตั้งต้น: เครื่องพิมพ์ `192.168.1.110:1024`, Checksum เปิด, Module `497,498,499,500`, 40 ตัวอักษร/field, Code system `UNICODE` (บันทึกใน `config.json` ข้างไฟล์โปรแกรม)

ปุ่มลัด: `Esc` ล้าง • `F2` โฟกัสช่องสแกน • `F5` ส่งซ้ำล่าสุด

## สร้างไฟล์ .exe (Windows)

```bash
pip install pyinstaller
pyinstaller CCS3000.spec
```

ไฟล์อยู่ที่ `dist/CCS3000/CCS3000.exe`

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `ccs3000_app.py` | หน้าจอแอป, การสแกน, การแบ่งข้อมูล, ส่งข้อมูล |
| `ccs3000_comm.py` | โปรโตคอลสื่อสารของเครื่องพิมพ์ (STX/ETX, Checksum, คำสั่ง STM) |
| `CCS3000.spec` | ตั้งค่า PyInstaller |

## Android Tablet (แอป Android)

โฟลเดอร์ `android/` คือแอป Android (Kotlin + Jetpack Compose) สำหรับแท็บเล็ต ทำงานเหมือนเวอร์ชัน Windows: ใช้โปรโตคอล CCS3000 ชุดเดียวกัน (STM, UNICODE hex, checksum) ส่งเข้า Text module ของเครื่องพิมพ์ผ่าน LAN

**ความสามารถ**
- สแกน QR / Barcode ด้วย **กล้อง** (สลับหน้า/หลังได้) หรือด้วย **เครื่องสแกน USB / Bluetooth** (ทำงานเหมือนคีย์บอร์ด จบด้วย Enter)
- เติมช่องว่างท้ายให้ครบ แบ่งเป็น field ละ N ตัว แล้วส่งเข้า module ตามลำดับ (debounce 80/200 ms เหมือน Windows)
- หน้าตั้งค่า (IP, Port, หมายเลข module, ตัวอักษรต่อ field, Message no., Code system, Checksum) และ **ทดสอบการเชื่อมต่อ** (ส่ง `TEST M<n>` เข้าทุก module — มีหน้าต่างยืนยันก่อน)
- ส่งซ้ำข้อมูลล่าสุด (ปุ่ม / F5), ล้าง (ปุ่ม / Esc), F2 กลับช่องสแกน, แถบสถานะสี, ตารางผลต่อ module, Log

**ติดตั้ง**
1. ไปที่แท็บ *Actions* → workflow **Android APK** → เปิดรอบล่าสุดที่เขียว → ดาวน์โหลด artifact `ccs3000-ink-tablet-apk` (หรือไฟล์ในหน้า *Releases* เมื่อ push tag `android-v1.0.0`)
2. คัดลอก `ccs3000-ink-tablet.apk` ไปที่แท็บเล็ต เปิดไฟล์แล้วอนุญาต “ติดตั้งแอปจากแหล่งที่ไม่รู้จัก”
3. เปิดแอป → แท็บ **ตั้งค่า** ใส่ IP/Port ของเครื่องพิมพ์ → **ทดสอบการเชื่อมต่อ** → **บันทึก**
4. แท็บเล็ตต้องอยู่ในเครือข่าย LAN เดียวกับเครื่องพิมพ์ — ผ่าน Wi-Fi/switch หรือ **สายแลนตรง** (ต้องใช้ตัวแปลง USB-LAN, ตั้ง IP ตายตัวของแท็บเล็ตให้อยู่วงเดียวกับเครื่องพิมพ์ เช่น `192.168.1.50`/`255.255.255.0`, แล้วเลือก “เครือข่าย = สายแลน” ในหน้าตั้งค่า เพื่อให้แอปส่งผ่านสายแลนแม้ Wi-Fi เปิดอยู่) · ครั้งแรกที่กด “สแกนด้วยกล้อง” แอปจะขอสิทธิ์กล้อง

**Build เอง**: ต้องใช้ JDK 17 + Android SDK 34 → `cd android && ./gradlew :core:test :app:assembleDebug` (APK อยู่ที่ `android/app/build/outputs/apk/debug/`) — โมดูล `:core` (โปรโตคอล/payload/sender) เป็น Kotlin ล้วน ทดสอบได้โดยไม่ต้องมี Android SDK
